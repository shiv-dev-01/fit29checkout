# FIT29 Checkout

Checkout for **FIT29**. Shoppers choose a treatment, enter contact and shipping details, apply a coupon when one is offered, pay, and reach the order confirmation page.

The repository name is `fit29checkout` because this project is the checkout code for FIT29.

## Stack

- React
- Create React App
- React Router
- Axios
- Tailwind CSS
- styled-components
- React Hot Toast

## Requirements

- Node.js 18 or later
- npm

## Run locally

```bash
git clone https://github.com/shiv-dev-01/fit29checkout.git
cd fit29checkout
npm install
npm start
```

The dev server opens at http://localhost:3000.
